# Erro 2fc60b760a511d54

```
Imagem base sem versão fixa: python:latest
```

- **Módulo:** deploy
- **Ocorrências:** 1
- **Primeira vez:** 2026-11-23 01:34:05
- **Última vez:** 2026-11-23 01:34:05

## Guia de solução

### O que aconteceu

O Dockerfile parte de uma imagem sem versão definida (ou com a etiqueta 'latest').

### Por que acontece

'latest' muda com o tempo. O mesmo Dockerfile pode funcionar hoje e quebrar semana que vem, quando a imagem for atualizada.

### Como resolver

1. Troque a linha FROM por uma versão específica, por exemplo: FROM python:3.12-slim (em vez de FROM python ou python:latest).  
2. Para ver as versões disponíveis, abra a página da imagem em hub.docker.com e use a aba Tags.  
3. Refaça a imagem (docker build) e rode os testes.

### Como confirmar que resolveu

Rode a análise de novo. O aviso deve sumir.

### Se não funcionou

Se a versão que você usa hoje não é conhecida, rode 'docker run IMAGEM python --version' (ajuste para a sua imagem) para descobri-la.
